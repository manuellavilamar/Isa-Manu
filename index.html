Como criar o token (1 min)

  1. No GitHub, clique na sua foto de perfil (canto superior direito) → Settings.
  2. Lá no fim da barra lateral esquerda, clique em Developer settings.
  3. Clique em Personal access tokens → Fine-grained tokens → Generate new token.
  4. Dê um nome (ex: "calendario") e em Expiration escolha No expiration (não expira).
  5. Em Repository access, escolha Only select repositories e selecione o repositório do seu calendário.
  6. Em Permissions → Repository permissions, procure por Contents e mude para Read and write.
  7. Clique em Generate token no final da página. Copie o token (começa com github_pat_).
  8. Cole ele no campo "Token de acesso" junto com seu usuário e nome do repositório. As duas colam os mesmos dados.

O token fica salvo apenas no navegador de cada uma (não no site). Se quiser revogar um dia, é só apagar o token no GitHub.
